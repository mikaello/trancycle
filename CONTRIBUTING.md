# Contributing to Trancycle

Trancycle welcomes new cycling concepts, translations, corrections, sources, and rights-cleared images.

## The easiest path

No knowledge of Git, Markdown, or the future site schema is required.

- [Suggest a new cycling term](https://github.com/mikaello/trancycle/issues/new?template=new-term.yml).

- [Suggest a translation](https://github.com/mikaello/trancycle/issues/new?template=translation.yml).

- [Report a correction](https://github.com/mikaello/trancycle/issues/new?template=correction.yml).

Explain what the term means in its cycling context so that words with several meanings can be reviewed correctly.

A link to a dictionary, manual, governing body, manufacturer document, or established cycling reference is especially helpful.

Suggestions without a source are still welcome, but they may remain provisional until reviewed.

## Concepts and terms

A concept is one particular meaning or thing, while a term is a label for that concept in one language.

For example, English `headset` and Bokmål `styrelager` label the same bicycle-component concept.

English `manual` can label two different concepts: a riding technique and an instruction book.

Translations should be added to an existing concept when the meaning is the same and proposed as a new concept when the meaning is different.

## Other languages

Translations beyond English and Bokmål are welcome.

Include the language name, language code if known, translation, intended meaning, region or usage notes, and supporting source.

Each language can have its own preferred term, alternatives, definition, and review status.

## Pull requests

Experienced contributors may edit concept files directly after the site and data migration are implemented.

Keep one concept per file and one sentence per line in Markdown prose.

Do not combine alternatives, usage labels, or explanations into an ambiguous comma-separated value.

Do not include copied descriptions or images unless their license permits reuse and all required attribution is recorded.

Run the repository's validation, formatting, test, and production-build commands before opening a pull request.

## Review

A suggestion may be accepted as provisional before a language or cycling-domain expert has reviewed it.

Reviewed entries need a clear meaning, a preferred term, supporting evidence, and a review date.

Trancycle is community-maintained and should not be represented as an official terminology standard.
